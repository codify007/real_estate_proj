
  # Real estate prediction website 

  Note: Please ensure you have installed <code><a href="https://nodejs.org/en/download/">nodejs</a></code>

  To preview and run the project on your device:
  1) Open project folder in <a href="https://code.visualstudio.com/download">Visual Studio Code</a>
  2) Create a virtual environment using the following commands on the terminal in the following order to install dependencies properly 
  3) python -m venv env
     source env/bin/activate       # On Windows: env\Scripts\activate
     pip install -r requirements.txt

  4) Lastly Run `python3 server.py` to view project in browser on localhost:5000
